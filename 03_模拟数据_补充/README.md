# 补充模拟数据说明

本目录在不改动 `03_模拟数据/` 九张原表的前提下，提供一组**独立的分析练习数据**。运行 `python3 scripts/generate_supplemental_sim_data.py` 可复现；运行 `python3 scripts/validate_supplemental_sim_data.py` 可检查主键、时间可得性、部分跨表对账与恒等式。全部为构造数据，不是生产日志、媒体后台真实导出或真实实验。

## 时间与口径

- 原表 `ads_rta_media_daily` 的转化字段是首登 cohort 的离线 T7 终值。快照表用终值按固定比例**构造** T0 22:07、T3 23:59、T7 23:59 的累计观察值；`as_of` 晚于 2026-09-26 的行不生成。T7 仅对 `cohort_date <= 2026-09-19` 成熟。它可以测试产品是否尊重时点，但**不能证明这些数字在历史时点真实可见**。
- 媒体后台模拟的是点击归因下的“申完回传”；我方模拟的是首登 cohort。两者没有逐人归因桥，数字不同不能直接判定任一方错误。媒体行的花费与对应 T0 快照花费同时间对齐。
- 竞价表的请求、参竞、竞得是从原表曝光和参竞率反推的构造量；分组预算从媒体总预算分配，并保证每个 `date + media + segment_type` 分组预算、花费分别汇总到媒体日表。腾讯的 RTA 策略切分和抖音的账户组切分不可互相相加。它们支持漏斗和余量演练，不提供真实拍卖失败原因。
- 回传表的候选数取原表授信数。原表回传比例是独立构造的连续值，本表转成整数消息计数后允许小于 1 个百分点的舍入误差。`规则排除人数` 与 `发送失败人数` 是不同环节。
- 放款表与原表授信、发起、动支人数严格对账；“未发起”原因仍未知，不能直接归为用户不愿借。拒绝码为按汇总数构造的模拟分布，不能替代真实逐笔日志。
- 模型 PSI、KS 是独立构造的监控数值，没有逐用户分数或模型分桶映射；可用于考察是否联合检查业务变化，**不能单独证明模型导致业务变化**。KS 在模拟标签未成熟时留空。
- Vintage30 逾期人数从原质量表的比率与原细分表动支样本数推导，按人数取整；未到成熟日的比率和人数留空。它不能回答近期 cohort 的实际 30 天表现。
- 审计表比较发生日花费，避开将未来 T7 终值写成次日已入仓的时间穿越。待核对差额只是数据质量线索，不直接证明哪一侧出错。
- 告警表是单个 22:07 时点的**规则重放**。T0 截至 22:07 的 CPS 阈值示例设为 1.3074（按原 0.54 终值阈值与本模拟的花费／转化观察比例等比校准），安全过件率阈值为 0.17；两者均带样本门槛。**未成熟 CPS 不能直接套用 T7 阈值 0.54。**`sent=否` 表示没有模拟真实推送记录。它不能证明“过去每天有没有报警”。
- 2026-09-27 掉量数据带独立 `scenario_id`，只用于假设场景测试；不是对原历史数据的延长，也没有被现有产品自动加载。当天没有模拟 T7 转化。比较 9 月 26 日同期小时花费时，仅可看投放发生量。
- 旧规则测试样本有基础量、`旧卡片CPS_关键字段` 与少数外部输入指标；其余 cpcl、安全过件率、授信成本、授信单产、平均额度、动支率和额度使用率应在评测时现算。`SIM_MISSING_AMOUNT` 的首借金额及旧卡片 CPS 同时为空，表示**关键字段缺失**，不是 0；按旧项目 `main.py` 的卡片字段检查应跳过该渠道。腾讯计费比是模拟外部输入，抖音留空；旧代码将计费比当作内外责任分水岭的结论不可直接作为正确答案。
- 腾讯双异常独立样本另有一套差异化的版位切分，用于验证多版位定位逻辑；原历史日表当前比较窗的 4 个版位涨幅几乎完全一致，不能用它验证“哪个版位单独拖累”的结论。

## 尚未补齐

1. **真实告警发送日志、媒体逐人归因与源头埋点**：现有表分别只提供规则重放、聚合口径对比和花费核账，不能还原真实操作记录。
2. **近期成熟 Vintage**：需要等待观察期或延长模拟时间；不得提前填充未来逾期结果。
3. **历史 3W2Q 提价的因果效应和放量增量**：原实验是不同客群的观察性对照。不能把事后拆分的聚合数伪称为随机实验；若要练习因果判断，应另建有事前随机分桶、执行日志及干扰检查的独立实验场景。
4. **自动接入产品**：当前补充文件不会被 `agent_mvp` 默认读取。把它们接入分析链还需要工具层、指标口径和对应评测用例的改造。

## 建议练习题

- 在 2026-09-27 18:59 的独立场景中，抖音消耗低于前日同小时多少？预算是否撞线？下降发生在请求、参竞还是竞得环节？哪些原因仍无法判定？
- 2026-09-22 两渠道的花费源头与入仓为何对不上？在排查完成前是否应直接调价？
- 腾讯 PSI 上升的那几日，已成熟业务 cohort 的安全过件率和 CPS 如何变化？能否证明由模型版本导致？
- 回传比例下降时，符合回传规则的人数、发送失败数各变化多少？
