# 02 获客业务流程

---

## 一、完整用户链路

```text
请求 → 出价 → 竞得 → 曝光 → 点击 → 首登 → 申完 → 授信 → 发起 → 动支 → 还款 / 逾期
                                               安全授信 ⊂ 授信（授信户中 A 卡前 3 组）
```

### 各节点定义

| 节点 | 定义 | 归属方 | 关键机制 |
|---|---|---|---|
| **请求** | 媒体把待评估用户的设备信息下发给业务方 | 媒体发起 / 业务方响应 | RTA 实时接口，毫秒级 |
| **出价** | 业务方根据模型分与规则决定是否参竞、出价多少 | 获客策略 / 获客模型 | `基础出价 × preA系数 × preG系数` |
| **竞得** | 在媒体拍卖中胜出，拿到该次曝光机会 | 媒体 | `eCPM = 出价 × pCTR × pCVR` |
| **曝光** | 广告展示给用户 | 媒体 | CPM 的分母 |
| **点击** | 用户点击广告 | 素材 / 定向 | **口径风险，见第三节** |
| **首登** | 用户首次登录 App 或小程序 | 产品 / 承接链路 | 首登成本的分母 |
| **申完** | 用户填写信息并提交借款申请 | 产品 / 风险前置 | 申完率的分母 |
| **授信** | 用户通过贷前审批并获得额度 | **风险主责** | 授信率；额度由额度模型给出 |
| **安全授信** | 授信环节 **A 卡分组在前 3 组**的授信用户，即风险视角的优质客户 | **风险主责** | 安全过件率 = 安全授信数 ÷ 申完数；安全授信是授信子集 |
| **发起** | 用户在授信后发起借款申请 | 产品 / 资金 | 授信发起率 |
| **动支** | 借款成功到账（= 首借） | 资金 / 技术链路 | 发起动支率 |
| **还款 / 逾期** | 按期还款或发生逾期 | 贷后 | Vintage30 等贷后指标 |

> ⭐ **两个容易被忽略的事实**：
> 1. **安全授信户是授信环节 A 卡前 3 组的用户**，属于授信户中的风险优质客群；安全过件率的分母仍是**申完数**，不是授信数。安全授信不是漏斗上的独立环节。
> 2. **`发起 → 动支` 在本环境的稳定水位约 95%。** 显著下降应优先核查放款执行链路，同时检查发起后的审批、资金策略、数据完整性和口径变化；仅凭该比率不能断定故障类型。

## 二、信息流 vs 精准营销（本环境只覆盖信息流）

| | 信息流（本环境覆盖） | 精准营销（不在本环境范围） |
|---|---|---|
| 载体 | 抖音、腾讯、快手、百度等 | 短信、Push、私域 |
| 链路 | 请求 → 出价 → 竞得 → 曝光 → 首登 → … | 撞库 → 频控 → 黑名单 → 老户 → 短信 → 首登 → … |
| 结算 | 按转化优化（oCPX） | 常按约定转化结算 |
| 主要风险 | 成本、质量、规模 | 投诉、频控、结算口径 |

## 三、⚠️ 口径风险：本环境刻意保留的复杂性

源业务中，"点击"在不同系统里定义不同，量级差异可达数十倍。本环境为避免歧义，**统一采用一种定义**，但要求分析者在使用前必须确认：

| 概念 | 本环境的定义 | 备注 |
|---|---|---|
| **点击** | **素材级广告点击**（用户点击了这条广告） | 曝光→点击率约 **0.8%（腾讯）/ 1.8%（抖音）** |
| **点击 → 首登** | 点击后完成首次登录的比例 | 约 **0.50%** |

【源资料未确认】真实业务中还存在"RTA 请求级点击""落地页点击"等口径，量级与素材级点击完全不同。**任何使用"点击率 / 点击-首登率"的分析，都必须先声明是哪一种口径。**

> ⚠️ **同一份材料内混用时间窗是本业务真实发生过的错误。** 本环境的转化人数及首借金额按首登 cohort 的 T0–T7 终值构造；花费、曝光、点击等投放字段按当日记录。分析时须说明两类字段的日期如何对齐（详见 03 文档）。

## 四、两个渠道的业务特征差异

基于本环境 2026-08-10 ~ 08-23（14 天）的稳定水位：

| 环节 / 指标 | 腾讯 | 抖音 |
|---|---|---|
| 日花费 | 37.4 万 | 40.2 万 |
| 日曝光 | 18.7 M | 9.4 M |
| 日点击 | 144 K | 165 K |
| 日首登 | 720 | 836 |
| 日申完 | 273 | 360 |
| 日授信 | 161 | 229 |
| 日动支 | 59 | 79 |
| 曝光→点击 | **0.77%** | **1.75%** |
| 点击→首登 | 0.500% | 0.506% |
| 首登→申完 | 37.9% | **43.0%** |
| 申完→授信 | 59.0% | **63.5%** |
| 申完→安全（安全过件率） | **19.4%** | **21.9%** |
| 授信→发起 | 38.6% | 36.0% |
| 发起→动支 | 95.2% | 95.6% |
| **授信单产** | **4,992 元** | **4,229 元** |
| **平均授信额度** | **29,554 元** | **25,468 元** |
| 额度使用率 | 46.1% | 48.2% |
| **授信成本** | **2,323 元** | **1,758 元** |
| **CPS** | **0.465** | **0.416** |
| 计费比 | 1.266 | 1.021 |
| CPM | 20.0 元 | 42.6 元 |

**三个必须记住的渠道差异**：

1. **腾讯的平均额度更高、单产更高、但授信成本也更贵** → 腾讯 CPS 高于抖音。
2. **抖音的转化链路效率更高**（首登→申完、申完→授信都更好）。
3. **两个渠道的绝对量级差异巨大**，因此**同一个固定阈值不可能对两个渠道同时有效**（详见 03 文档"阈值风险"）。

## 五、运营节奏与观测窗口

| 项 | 设定 |
|---|---|
| 常规观测节奏 | 每日多次，T 日 vs 昨日对比 |
| 短周期复盘 | 近 7 天 vs 前 7 天 |
| 策略复盘 | 变更前 8 天 vs 变更后 8 天（配合对照组） |
| 长周期复盘 | 月度 / 季度 |
| 数据延迟 | 曝光、花费等当日字段可在日结后完整；以首登日为切口的 T0–T7 转化终值需在该 cohort 完成 7 天观察期后才成熟 |

> **本环境预先提供了全部日期的 T0–T7 终值，供离线 Benchmark 使用。** 数据表有 9 月 22 日的终值，不代表在 9 月 22 日当天即可观测到这些终值。做真实时点判断时，须检查每个首登 cohort 是否已完成观察期。

## 六、外部环境因素

| 因素 | 影响 |
|---|---|
| 周末 | 花费与转化量普遍低于工作日（约 −4% ~ −5%） |
| 素材生命周期 | 素材 CTR 随上线天数**指数衰减**，有效投放周期约 30 天 |
| 素材供给空窗 | 若一段时间无新素材上线，大盘 pCTR 会整体下滑 |
| 竞价环境 | 行业竞争加剧会推高 CPM，压缩可获取曝光 |
| 季节与政策 | 【源资料未确认】本环境未模拟 |

## 七、本业务的三条"常识性"事实

1. **花费持平但转化数下降，等价于单位成本上升。** 这是成本类问题的第一现场，必须区分"钱花多了"与"同样的钱买到的量少了"——**两者的责任方完全不同**。
2. **拿到授信不变现，等于钱白花。** 授信后不动支是真实的业务损失，且往往在发生 1–2 周后才传导到成本指标。
3. **质量问题的黄金干预期是"质量已坏但成本未坏"的窗口。** 一旦质量问题传导到 CPS，通常已过去 3–7 天。
