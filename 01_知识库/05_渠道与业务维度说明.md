# 05 渠道与业务维度说明

> 本文件列出本环境**实际可用**的全部维度及其取值。分析前先看这里，避免假设出不存在的维度。

---

## 一、维度总览

| 维度 | 归属渠道 | 取值数 | 出现在哪些表 |
|---|---|---|---|
| **媒体** | 全部 | 2 | 全部表 |
| **RTA 策略** | 腾讯 | 4 | 细分表、质量表、投放表 |
| **版位** | 腾讯 | 4 | 细分表 |
| **账号** | 抖音 | 4 | 细分表、质量表、投放表 |
| **客群分层（W/Q）** | 腾讯 + 抖音 | 5 | 细分表、漏斗表 |
| **素材** | 抖音 | 12（滚动） | 素材表 |
| **实验分组** | 腾讯 + 抖音 | 2 | 策略实验表 |
| **日期** | 全部 | 56 天 | 全部表 |

> ⚠️ **注意**：本环境**没有**"计划""广告位 ID""代理商"等维度。需要这些维度的分析无法完成。

---

## 二、媒体

| 取值 | 说明 |
|---|---|
| `腾讯` | 广点通，含 H5 场景 |
| `抖音` | 巨量引擎 |

**两个渠道的差异总结见 02 文档第四节。** 与维度相关的三点：

1. **主切分维度不同**：腾讯按「RTA 策略」切分，抖音按「账号」切分。
2. **计费比适用性不同**：腾讯适用，抖音不适用。
3. **量级不同**：抖音单日曝光约为腾讯的一半，但点击量更高。

---

## 三、腾讯 · RTA 策略

腾讯侧的投放按 **RTA 策略** 切分。本环境包含 4 个 RTA 策略。

> ⚠️ **策略名称为脱敏模拟标识。**
> 腾讯渠道**真实存在多个并列的 RTA 策略**（源资料中可见 `腾讯RTA策略01_202401`、`RTA策略_CPA出价` 等真实策略名），但**真实策略名与策略总数不属于可公开信息**。
> 因此本环境的**策略数量与命名均为模拟值**；**策略机制与业务属性依据真实业务结构构造**——即各策略均运行在 **RTA 系数出价** 机制下：
>
> ```text
> 最终出价 = 基础出价 × preA系数 × preG系数
> ```
> （见 `04_RTA与媒体投放机制.md` 第四节）

| RTA 策略（脱敏模拟标识） |
|---|
| `腾讯RTA策略_A` |
| `腾讯RTA策略_B` |
| `腾讯RTA策略_C` |
| `腾讯RTA策略_D` |

> ⚠️ **本环境不在公开材料中描述各策略的"优化目标"或业务优劣。**
> 策略之间在**成本、规模、质量、交易价值**上的差异，**必须由分析者从数据中自行得出**，本文件不做预设。
>
> ⚠️ **各策略的消耗占比随时间变化**，同样需要从数据中查询。

## 四、腾讯 · 版位

| 版位 | 消耗占比 |
|---|---|
| 微信朋友圈 | 42% |
| 腾讯视频 | 26% |
| 腾讯新闻 | 20% |
| QQ 浏览器 | 12% |

**本环境设定版位之间的转化效率差异很小**（各版位指标接近大盘）。版位维度主要用于验证"问题是全局性还是局部性"。

## 五、抖音 · 账号

抖音侧的投放按 **账号** 切分。本环境的 4 个账号沿用源资料中的账号类型命名：

| 账号 | 说明 |
|---|---|
| `授信账户-常规` | 授信回传账号（常规） |
| `授信账户-合作方A` | 授信回传账号（合作方 A） |
| `ROI账户-常规` | ROI 回传账号（常规） |
| `ROI账户-合作方A` | ROI 回传账号（合作方 A） |

> **【事实·源知识库】** 抖音渠道的账号按「回传账户类型 × 合作方」划分：授信账户 / ROI 账户，各有常规与合作方变体；账户类型决定该账号的回传门槛与回传时效（见 04 文档第五节）。
>
> ⚠️ **合作方名称已脱敏**（源资料中的真实资金方名不公开），`合作方A` 为模拟标识。
>
> ⚠️ **各账号的消耗占比与业务表现需要从数据中查询**，本文件不做预设。

> 【源资料未确认】真实业务中账号还按**执行模式**分为三类（代理决策+代理执行 / 业务方决策+代理执行 / 业务方决策+系统执行）。本环境**不包含代理角色**。

## 六、客群分层（W/Q 二维）

本环境将 preG 意愿层与 preA 质量层简化为 5 个**具名客群组合**（而非完整的 5×5=25 格）：

| 客群 | 含义 | 腾讯消耗占比 | 抖音消耗占比 |
|---|---|---|---|
| `5W4Q` | 高意愿 · 高质量 | 22% | 22% |
| `4W3Q` | 中高意愿 · 中高质量 | 29% | 29% |
| **`3W2Q`** | 中意愿 · 中低质量 | **14%** | **14%** |
| **`3W3Q`** | 中意愿 · 中质量（与 3W2Q 相邻） | **11%** | **11%** |
| `2W3Q` | 低意愿 · 中质量 | 24% | 24% |

> ⚠️ **本环境只有这 5 个具名客群，不存在完整的 W1–W5 × Q1–Q5 分档数据。** 任何要求"下钻到具体 W/Q 分档"的分析在本环境内无法完成，只能在这 5 个客群内比较。

**客群分层是策略实验的主要维度**：RTA 出价系数按客群配置，因此客群级数据是判断策略效果的基础。

---

## 七、抖音 · 素材

本环境包含 12 条抖音素材，按上线时间滚动投放，**同时在线约 3–5 条**。

| 字段 | 说明 |
|---|---|
| 素材 ID | `DY_CRE_01` ~ `DY_CRE_12` |
| 素材类型 | 视频-口播 / 视频-剧情 / 视频-图文 |
| 上线日期 | 素材首次投放日期 |
| 上线天数 | 数据日 − 上线日期 |
| CTR | 素材的曝光→点击率 |
| 完播率3秒 | 【源资料未确认】本环境按 CTR 派生，仅作辅助参考 |
| 消耗占比 | 该素材占抖音总花费的比例 |

**素材的滚动规律**：
- 有效投放周期约 **30 天**，超出后自动退出；
- CTR 随上线天数**指数衰减**；
- 新素材上线后前 2 天份额爬坡；
- **若一段时间无新素材上线，大盘 CTR 会整体下滑**——这是"素材疲劳"在渠道层面的表现。

---

## 八、实验分组

策略实验表提供 **实验组 / 对照组** 两组成对数据：

| 分组 | 客群 | 出价系数变化 |
|---|---|---|
| 实验组 | `3W2Q` | 按变更记录调整 |
| 对照组 | `3W3Q` | 保持不变（相邻客群，作为参照） |

> ⚠️ **实验设计的已知局限**：本环境的实验**不是设备 ID 分桶实验**，而是客群级对照。因此存在**实验污染风险**：
> - 账户之间会互相竞争（媒体在多层级都有模型预估）；
> - 实验组的规模扩张可能影响对照组可竞得的流量；
> - 渠道级的外部事件会同时影响两组。
>
> **分析时必须检查对照组是否"干净"**——如果对照组在后窗也发生了显著变化，说明存在共同的外部冲击，需要剔除或单独说明。

## 十、维度的可用性说明（重要）

| 分析需求 | 本环境能否支持 |
|---|---|
| 按渠道对比 | ✅ 支持 |
| 按 RTA 策略（腾讯）下钻 | ✅ 支持 |
| 按账号（抖音）下钻 | ✅ 支持 |
| 按版位（腾讯）下钻 | ✅ 支持 |
| 按客群分层对比 | ✅ 支持（仅 5 个具名客群） |
| 按素材分析（抖音） | ✅ 支持 |
| 按实验组/对照组对比 | ✅ 支持 |
| 跨渠道横向一致性校验 | ✅ 支持（两渠道同日数据可比） |
| 时间序列 / 趋势 / 形态分析 | ✅ 支持（56 天日级） |
| **按具体 W/Q 分档（如 3W2Q 之外的格子）** | ❌ 不支持 |
| **按计划 / 广告位 / 代理商** | ❌ 不支持 |
| **小时级 / 分钟级时序** | ❌ 不支持（本环境为日级） |
| **明细级抽样（用户级）** | ❌ 不支持 |
| **模型分分布 / PSI / KS** | ❌ 不支持 |
