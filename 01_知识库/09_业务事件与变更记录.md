# 09 业务事件与变更记录

> ⚠️ **本文件的写法约定**：只记录"**哪一天发生了什么变更**"，**不记录任何"某变更导致了某指标异常"的结论**。
> 变更与异常之间的因果关系，必须由分析者从数据与时间关系中自行建立并验证。

---

## 一、为什么需要变更记录

业务指标异常有两类来源：

| 来源 | 特征 | 处置 |
|---|---|---|
| **外部/环境变化** | 无内部变更与之对应 | 只能适应或对冲 |
| **内部变更** | 时间上与变更记录吻合 | **可定位、可回滚、可评估** |

因此：**任何一次归因分析，都必须先对照变更记录。** 时间上吻合的变更，是最高优先级的候选原因。

> ⚠️ **但时间吻合不等于因果。** 同一时期可能存在多个变更，也可能存在"变更了但没有效果"的情况。需要结合数据验证，而不是直接认定。

---

## 二、变更记录的字段

| 字段 | 说明 |
|---|---|
| 变更日期 | 变更生效日期 |
| 变更时间 | 变更生效的具体时点 |
| 变更类型 | 见下方分类 |
| 变更对象 | 具体到渠道 / RTA 策略 / 账号 / 客群 / 素材 |
| 变更前 / 变更后 | 变更内容 |
| 操作方 | 责任方 |
| 备注 | 操作方填写的备注（**备注是操作方的意图描述，不等于事实结论**） |

---

## 三、变更类型分类

| 类型 | 影响什么 | 生效速度 |
|---|---|---|
| **素材上线 / 下线** | pCTR → 曝光 → 消耗 → 成本 | 上线后 1–2 天爬坡；下线当日生效 |
| **预算调整** | 消耗上限 → 消耗结构 | 当日生效 |
| **定向调整** | 可触达人群 → 曝光、人群结构 | 当日生效 |
| **排除包更新** | 进入的人群集合 | 当日生效 |
| **回传规则调整 / 复核** | 可能改变符合规则的样本量与结构；需核对是否实质调整及后续投放变化 | 配置可当日生效，后续影响须验证 |
| **模型上线** | 分档结果 → 人群结构 | 当日生效，效果可能渐进显现 |
| **RTA 出价系数调整** | 特定客群的出价 → 规模/成本/质量 | 当日生效，质量效果滞后 1–2 天 |
| **回传链路异常 / 恢复** | 可能改变应回传对象的发送成功率及媒体学习样本 | 链路即时受影响；pCVR、CPS 是否变化须在后续窗口验证 |

## 五、使用变更记录的正确姿势

### 5.1 三步法

| 步 | 动作 |
|---|---|
| 1 | **确定异常的起始时点**（突变点 / 趋势起点） |
| 2 | **在变更记录中找时间吻合的条目** |
| 3 | **用数据验证**：变更对象的指标变化，是否与变更内容方向一致、幅度合理 |

### 5.2 需要警惕的四种情况

| # | 情况 | 说明 |
|---|---|---|
| 1 | **变更了但没有效果** | 记录中有条目，但对应对象的指标没有变化 → 不是原因 |
| 2 | **多个变更同期发生** | 需要分别评估，或通过子组差异（只有 A 组被变更，B 组没有）来分离 |
| 3 | **变更的影响面比预期大** | 例如预算调整可能改变整个渠道的消耗结构，而不只影响被调整的对象 |
| 4 | **"备注"不等于事实** | 备注是操作方的意图描述。**判断实际效果要看数据，不看备注** |

### 5.3 特别提示：变更记录不是因果结论

| ❌ 错误读法 | ✅ 正确读法 |
|---|---|
| "某日有预算调整，所以 CPS 涨了" | "某日有预算调整；需先确认被调整对象的指标是否确实变化，并进一步验证是结构效应还是个体效应" |
| "某日调整了出价系数，所以规模涨了" | "该日有系数调整；需用对照组剥离同期大盘趋势，才能判断净效应" |
| "某日回传故障了，所以 CPS 会涨" | "该日回传短时故障；需检查后续 1–3 天 CPS 是否真的抬升，以及幅度是否与故障时长匹配" |

## 六、变更记录之外的事件

**并非所有值得关注的事件都在变更记录里。** 变更记录只记录"**人主动执行的配置变更**"。以下事件不会出现在变更记录中，但同样重要：

| 类型 | 例子 | 如何发现 |
|---|---|---|
| **自然衰减** | 素材 CTR 随上线天数衰减 | 从素材表的 CTR × 上线天数关系中观察 |
| **供给空窗** | 一段时间无新素材上线导致大盘 pCTR 整体下滑 | 从素材表的在投素材数与上线日期分布中观察 |
| **外部环境** | 大盘竞价加剧导致 CPM 上行 | 从 CPM 趋势与自身出价是否变化中反推 |
| **渐进劣化** | 承接链路效率缓慢下降 | 从转化率的持续趋势中观察 |
| **客群结构漂移** | 均值稳定但分布变化 | 从结构占比的变化中观察 |

> ⭐ **最后一条尤其重要**：**当一个指标在多个子组都正常、但大盘异常时，问题往往在"结构"而不是"个体"。** 结构变化不会出现在任何变更记录中。
