# `ads_rta_creative_daily` · 素材日级表

| 项 | 内容 |
|---|---|
| **表名** | `ads_rta_creative_daily` |
| **中文名** | 素材日级表 |
| **粒度** | `date` × `素材ID` |
| **主键** | `date` + `素材ID` |
| **行数** | 260 |
| **覆盖** | 仅抖音 |
| **文件** | `03_模拟数据/ads_rta_creative_daily.csv` |
| **用途** | 素材 CTR 与上线天数的关系分析、素材消耗结构、素材生命周期管理 |

---

## 字段说明

| 字段 | 类型 | 含义 |
|---|---|---|
| `date` | 日期 | 数据日期 |
| `media` | 字符串 | 固定为 `抖音` |
| `素材ID` | 字符串 | `DY_CRE_01` ~ `DY_CRE_12` |
| `素材类型` | 字符串 | `视频-口播` / `视频-剧情` / `视频-图文` |
| **`上线日期`** | 日期 | 素材首次投放日期 |
| **`上线天数`** | 整数 | `date` − `上线日期` |
| `花费` | 金额 | 该素材当日花费 |
| `曝光` / `点击` | 整数 | 该素材的曝光、点击 |
| **`CTR`** | 比率 | 点击 ÷ 曝光 |
| `完播率3秒` | 比率 | 【源资料未确认】按 CTR 派生的辅助指标，不代表真实的完播行为 |
| **`消耗占比`** | 比率 | 该素材占抖音当日总花费的比例 |

---

## ⭐ 核心用法：素材 CTR 与上线天数的关系

**做法**：把每条素材的 `CTR` 与其 `上线天数` 放在一起看，观察二者的关系。

| 可观察的现象 | 业务含义 |
|---|---|
| CTR 与上线天数呈负相关 | 存在素材随投放时长表现走弱的迹象；还需排查投放人群、版位和素材份额变化 |
| 在投素材数量偏少、上线天数整体偏大 | 素材供给可能不足 |
| 素材 CTR 与大盘 CTR 同向变动 | 可检查素材表现和份额对大盘实际 CTR 的构成贡献；不能据此量化素材对媒体预估 pCTR 的因果影响 |

**可能的传导机制**（需用各环节数据分别验证）：

```text
素材实际 CTR 走低 → 媒体预估 pCTR 可能走低 → eCPM 竞争力可能下降
                                                → 可获取曝光与消耗可能下降
```

> ⚠️ `参竞率`是参竞决策占可参竞请求的比例，不是 eCPM 排序结果。实际 CTR、媒体预估 pCTR、参竞率和曝光应分别核对；日级数据只能观察同期或跨日关联，不能确定日内传导顺序。本模拟数据的 `pCTR` 由对应细分的实际 `点击 ÷ 曝光` 加扰动构造，二者相关性不能充当现实中的因果证据。

## 关系

| 方向 | 说明 |
|---|---|
| **汇总** | 按 `date` 汇总本表的 `花费`/`曝光`/`点击`，等于 `ads_rta_media_daily` 中抖音的对应值 |
| **关联** | 与 `ads_rta_delivery_daily` 的 `pCTR` 可按日期比较趋势；本表没有账号、策略等细分键，不能按素材直接关联该表的细分行 |

## ⚠️ 使用注意

| # | 注意 |
|---|---|
| 1 | **本表只有抖音素材，没有腾讯素材数据。** 腾讯侧的素材分析在本环境内无法完成 |
| 2 | `上线天数` 与 `CTR` 的关系是本表的核心信息。**不要只看某一天的 CTR 绝对值**——必须结合上线天数 |
| 3 | `完播率3秒` 为派生构造值，仅与 CTR 正相关。**不应据其推导素材创意质量的结论** |
| 4 | 各素材的 `消耗占比` 之和 = 100%（当日）。**素材份额会随新素材上线而重新分配** |
| 5 | 素材的 `CTR` 经过归一化处理，**加权平均精确等于当日抖音大盘 CTR**（见 `ads_rta_media_daily` 的 `点击 ÷ 曝光`） |
