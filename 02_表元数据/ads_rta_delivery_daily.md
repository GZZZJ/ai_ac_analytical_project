# `ads_rta_delivery_daily` · 投放竞争力日级表

| 项 | 内容 |
|---|---|
| **表名** | `ads_rta_delivery_daily` |
| **中文名** | 投放竞争力日级表 |
| **粒度** | `date` × `media` × `segment_type` × `segment_name` |
| **主键** | 上述四字段 |
| **行数** | 448 |
| **覆盖** | 腾讯（`RTA策略` 4 个）+ 抖音（`账号` 4 个） |
| **文件** | `03_模拟数据/ads_rta_delivery_daily.csv` |
| **用途** | 规模类问题分析（消耗跑不出去）、竞价竞争力诊断、回传链路诊断 |

---

## 字段说明

| 字段 | 类型 | 含义 | 口径 |
|---|---|---|---|
| `date` / `media` / `segment_type` / `segment_name` | — | 维度键 | — |
| **`均分预算参考值`** | 金额 | 渠道日预算 ÷ 本维度细分个数得到的**均分参考值** | ⚠️ **不是该细分的真实预算配置** |
| **`消耗`** | 金额 | 该细分的当日实际花费 | 业务口径 |
| **`消耗进度`** | 比率 | 消耗 ÷ `均分预算参考值` | 仅作相对参考；**不能据此判断真实预算是否撞线** |
| **`基础出价`** | 金额 | 计划层基础出价 | 本环境全期固定 |
| `preA出价系数` | 系数 | 本模拟细分行的质量侧出价系数参考值 | 按细分标识构造；没有请求级 W/Q 分档明细 |
| `preG出价系数` | 系数 | 本模拟细分行的意愿侧出价系数参考值 | 按细分标识构造；没有请求级 W/Q 分档明细 |
| **`参竞率`** | 比率 | 参竞次数 ÷ 请求次数 | 下降优先检查请求结构、RTA 排除与超时；参竞后的竞价竞争力需另看竞得和曝光 |
| `曝光` | 整数 | 实际获得的曝光量 | — |
| **`CPM`** | 金额 | 消耗 ÷ 曝光 × 1000 | 竞价的价格侧 |
| **`pCTR`** | 比率 | 媒体侧**预估**点击率 | 媒体认为这次曝光会被点击的概率 |
| **`pCVR`** | 比率 | 模拟的媒体侧预估授信率 | 按同细分的 `授信数 ÷ 点击` 加小幅扰动构造；**不是** `动支数 ÷ 点击` |
| **`回传比例`** | 比率 | 模拟的应回传对象发送成功率 | 直接构造，与媒体表同渠道同日取值；无原始计数，不是规则覆盖率 |
| `回传比例变化幅度` | 比率 | 本日 − 前一日 | 本表为空白，请用 `ads_rta_media_daily` |

---

## ⭐ 核心用法：消耗跑不出去的穷举框架

```text
消耗 = 曝光量 × CPM ÷ 1000
曝光量 ← eCPM 竞争力 = Bid × pCTR × pCVR
```

**排查顺序**：

| 步 | 检查字段 | 若异常 → |
|---|---|---|
| 1 | `消耗` 是否被真实预算约束（须用 `ads_rta_media_daily.日预算` 与 `ads_rta_change_log`） | 预算撞线 |
| 2 | `基础出价` / `preA出价系数` / `preG出价系数` | 出价问题 |
| 3 | `pCTR` + `ads_rta_creative_daily.CTR` + `上线天数` | 素材疲劳 |
| 4 | `pCVR` + `回传比例` | 排查媒体预估与回传链路，但两者变化不能单独证明因果 |
| 5 | `参竞率` + `曝光` | 先区分参竞前的策略收缩和参竞后的竞价结果；本表无竞得数字段 |

> ⭐ **基础出价与出价系数未变化时，仍须检查预算、请求量、定向、参竞及流量供给。** pCTR / pCVR 用于分析参竞后的竞争力，不能穷举所有消耗下降原因。
>
> ⚠️ **`pCTR` / `pCVR` 是按实际比率加扰动构造的模拟预估值。** 比较时须对齐目标、粒度与分母：`pCTR` 对比同细分的 `点击 ÷ 曝光`，`pCVR` 对比同细分的 `授信数 ÷ 点击`。它们与实际比率有差异，不能直接认定媒体模型失准。

## 关系

| 方向 | 说明 |
|---|---|
| **上游** | 与 `ads_rta_segment_daily` 同粒度 |
| **关联** | 抖音素材表只能按 `date` 聚合后与渠道大盘比较；没有“账号 × 素材”的交叉键，不能把素材行直接 JOIN 到账号行后求和 |
| **关联** | 对比同粒度实际比率时，按 `date + media + segment_type + segment_name` 关联 `ads_rta_segment_daily` |

---

## ⚠️ 使用注意

| # | 注意 |
|---|---|
| 1 | ⚠️ **`均分预算参考值` 不是真实预算。** 它是"渠道日预算 ÷ 细分个数"的均分值，**全期恒定，不随任何预算调整变化**。真实的分 RTA 策略/分账号预算调整记录在 `ads_rta_change_log`（字段为"日出价预算"）。**判断预算是否变化、是否撞线，请用 `ads_rta_media_daily.日预算` + `ads_rta_change_log`，不要用本字段** |
| 2 | **`pCTR` / `pCVR` 为模拟预估值**，本环境按细分实际比率加小幅扰动构造；`pCVR` 的目标为授信，而媒体表的 `转化数` 为动支。**不应据此推导媒体模型参数或把二者差异解释成预估误差** |
| 3 | **`回传比例变化幅度` 在本表为空**，请使用 `ads_rta_media_daily` 的同名字段 |
| 4 | 抖音侧的 `pCTR` 与素材表的大盘 CTR 同源，因此**抖音细分之间的 pCTR 差异较小**；素材差异请看 `ads_rta_creative_daily` |
| 5 | 本表**不含**"素材上线天数"字段，素材生命周期请看 `ads_rta_creative_daily` |
| 6 | 本表没有请求数、参竞次数和竞得次数；`参竞率` 不能复算，`曝光` 也不能单独拆出可参与流量不足与竞价未竞得各占多少 |
