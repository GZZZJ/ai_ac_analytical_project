# `ads_rta_segment_daily` · 细分流量日级表

| 项 | 内容 |
|---|---|
| **表名** | `ads_rta_segment_daily` |
| **中文名** | 细分流量日级表 |
| **粒度** | `date` × `media` × `segment_type` × `segment_name` |
| **主键** | 上述四字段 |
| **行数** | 1,320 |
| **文件** | `03_模拟数据/ads_rta_segment_daily.csv` |
| **用途** | 下钻定位：问题集中在哪个 RTA 策略 / 版位 / 账号 / 客群 |

---

## 字段说明

| 字段 | 类型 | 含义 |
|---|---|---|
| `date` | 日期 | 数据日期 |
| `media` | 字符串 | `腾讯` / `抖音` |
| `segment_type` | 字符串 | 切分维度：`RTA策略` / `版位` / `账号` / `客群分层` |
| `segment_name` | 字符串 | 该维度下的取值 |
| `花费` | 金额 | 该细分的花费 |
| `曝光` / `点击` | 整数 | 该细分的曝光、点击 |
| `首登数` / `申完数` / `授信数` / `安全授信数` / `发起数` / `动支数` | 整数 | 该细分的漏斗各级人数 |
| `首借金额` | 金额 | 该细分的首借金额 |
| `授信额度合计` | 金额 | 该细分的授信额度合计 |
| `安全首借金额` | 金额 | 该细分安全用户的首借金额 |
| `转化数` | 整数 | = 该细分的 `动支数` |

---

## 各 `segment_type` 的取值

### `RTA策略`（仅腾讯，4 个）

`腾讯RTA策略_A` / `腾讯RTA策略_B` / `腾讯RTA策略_C` / `腾讯RTA策略_D`

> ⚠️ **策略名称为脱敏模拟标识。** 腾讯渠道真实存在多个并列的 RTA 策略，但真实策略名与数量不公开。**本文件不描述各策略的业务优劣**——其成本/规模/质量差异需从数据中计算。详见 `01_知识库/05_渠道与业务维度说明.md` 第三节。

### `版位`（仅腾讯，4 个）

`微信朋友圈`、`腾讯视频`、`腾讯新闻`、`QQ浏览器`

### `账号`（仅抖音，4 个）

`授信账户-常规` / `授信账户-合作方A` / `ROI账户-常规` / `ROI账户-合作方A`

> 账号类型与命名沿用源资料结构；**合作方名已脱敏**。

### `客群分层`（腾讯 + 抖音，5 个）

`5W4Q`（22%）、`4W3Q`（29%）、`3W2Q`（14%）、`3W3Q`（11%）、`2W3Q`（24%）

> 见 `01_知识库/05_渠道与业务维度说明.md`。

## ⚠️ 使用注意

| # | 注意 |
|---|---|
| 1 | **每个 `segment_type` 是同一大盘的独立切分，之和精确等于大盘。** ❌ 不要跨 `segment_type` 相加 |
| 2 | `RTA策略` 与 `版位` 只有腾讯；`账号` 只有抖音。查询时需带 `media` 条件 |
| 3 | **`客群分层` 只有 5 个具名客群**，不是完整的 W1–W5 × Q1–Q5 分档。需要更细的分档时本表无法支持 |
| 4 | **某些细分在小样本下会抖动。** 例如腾讯 `腾讯RTA策略_C` 的日授信数约 15、日动支约 7。单日比率指标噪音较大，**建议用 7 天窗口聚合后再比较** |
| 5 | 细分的曝光/点击按花费份额分配，因此**细分的 CTR 与大盘一致**；若需要素材级 CTR，请看 `ads_rta_creative_daily` |
| 6 | 本表**不包含** `回传比例`、`计费比`、`参竞率` 等投放侧字段，需从 `ads_rta_delivery_daily` 获取 |
