# ads_rta_adgroup_hourly

| 项 | 说明 |
|---|---|
| 中文名 | 广告组小时级投放过程表 |
| 粒度 / 主键 | `date × hour × media × ad_group` |
| 覆盖范围 | 2026-07-29 至 2026-09-26，腾讯和抖音，合计 7,320 行 |
| 时间语义 | `hour=14` 表示当地时间 14:00–14:59；`hour` 为 0–23 的整数 |
| 生成方式 | `python3 scripts/generate_intraday_data.py`；基础投放量由媒体日表拆分，T0/T3/T7 转化为聚合层模拟值，不是实测小时日志 |

## 字段

| 字段 | 类型 | 口径 |
|---|---|---|
| `date` | 日期 | 投放日期，YYYY-MM-DD |
| `hour` | 整数 | 当地小时，0–23 |
| `media` | 文本 | 腾讯、抖音 |
| `ad_group` | 文本 | 媒体下的模拟广告组 ID；腾讯 `TX_AG_01`–`04`，抖音 `DY_AG_01`–`04` |
| `花费` | 金额 | 该小时该广告组的投放花费，元 |
| `曝光` | 整数 | 该小时该广告组的曝光次数 |
| `点击` | 整数 | 该小时该广告组的点击次数 |
| `首登数` | 整数 | 该小时该广告组带来的首登人数 |
| `30天以上未申完老户归因触达数` | 整数 | 模拟首登超过 30 天、仍未申完且在该时段再次被归因触达的老户数；仅为聚合假设 |
| `归因触达人数` | 整数 | 本表模拟的归因 cohort 基数 = `首登数` + `30天以上未申完老户归因触达数` |
| `T0申完数` / `T3申完数` / `T7申完数` | 整数 | 该行归因 cohort 截至对应观察窗完成申完的累计人数 |
| `T0授信数` / `T3授信数` / `T7授信数` | 整数 | 对应观察窗累计授信人数 |
| `T0安全授信数` / `T3安全授信数` / `T7安全授信数` | 整数 | 累计授信人数中 A 卡前 3 组的人数，属于授信的子集 |
| `T0发起数` / `T3发起数` / `T7发起数` | 整数 | 对应观察窗累计发起借款人数 |
| `T0动支数` / `T3动支数` / `T7动支数` | 整数 | 对应观察窗累计成功动支人数 |
| `T0动支金额` / `T3动支金额` / `T7动支金额` | 金额 | 对应观察窗累计成功动支金额，元 |

## 使用约定

1. **无记录 ≠ 指标为零。** 未投放或未产生日志的广告组小时组合不生成行；已有行内的 `0` 是已记录的零值。分析停投覆盖率时先构造完整的广告组小时格，再标记“缺记录”，不能直接 `COALESCE(0)` 当作已观测的零。
2. 06:00–23:59 每个整点小时约占全表 **4.92% 的记录条数**；01:00–05:59 每个整点小时约占 1.64%。这只是**行数占比**，不是花费、曝光、点击或首登的数值占比。
3. 按 `date + media` 汇总**花费、曝光、点击、首登数**，严格等于 `ads_rta_media_daily` 的对应字段。广告组是新增切分，**不等同于**原日表中的 RTA 策略、版位、账号或客群分层；不能用名称直接关联。
4. 本表先在聚合层假定每个可归因触达只归入一个广告组小时行，再模拟该归因 cohort 的后续转化。没有用户触点明细，**不能验证真实末次触点、7/30 天追溯优先级、跨媒体抢归因或老户排除包执行情况**。`30天以上未申完老户归因触达数` 是场景假设，不是从真实用户行为推导。
5. `T0` 是归因触达当日 23:59 前，`T3` 是触达日后第 3 日 23:59 前，`T7` 是触达日后第 7 日 23:59 前；三者是**同一 cohort 的累计值**，不是事件实际发生在第 0/3/7 天或当小时的次数。任一指标应满足 `T0 ≤ T3 ≤ T7`。花费、曝光、点击按**发生小时**记录，不能把 T0/T3/T7 结果当作该小时已知的转化。
6. 原媒体日表的转化字段属于**首登日 cohort**；本表转化字段属于**归因触达时段 cohort**，还包含 30 天以上未申完老户，因此两表的转化人数和金额**不应按 `date + media` 强行对账**。两表可对账的只有第 3 条的四个基础字段。
7. 这些 T0/T3/T7 是离线预生成终值。例如在模拟观察日 2026-09-26，只有 `date ≤ 2026-09-19` 的 T7 成熟；当天盘中看不到当日 T0 终值。若要模拟“当天 14:07 的实时视图”，还需要独立构造带 `as_of` 的未成熟快照；本表只能用于事后日内 cohort 复盘。
8. 老户归因触达量按媒体日首登数的 12% 作为**纯模拟假设**生成；转化率参考原媒体日表各环节比例，再按聚合行分配，并非根据归因工作簿估计的真实老户人数或效率。因未造用户级触点，无法证明某次申完究竟应归入哪个广告组。
